# VK Реклама: Создать группу объявлений — MCP-инструмент (tool)

**MCP-инструмент (tool) для VK Рекламы:** Создаёт группу объявлений внутри кампании.

Техническое имя: `create_ad_group`

## Какую задачу решает

> Я хочу создать группу объявлений.

Создаёт группу объявлений внутри кампании.

## Когда использовать

Используйте эту возможность, когда нужен результат «Создать группу объявлений» без ручной работы в интерфейсе VK Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `adPlanId` — **обязательно**. Id родительской кампании.
- `name` — **обязательно**. Название группы объявлений.
- `objective` — **необязательно**. Цель группы, например site_conversions, leadads, traffic.
- `autobiddingMode` — **необязательно**. Стратегия аукциона, например max_goals.
- `budgetLimit` — **необязательно**. Общий бюджет в валюте аккаунта.
- `budgetLimitDay` — **необязательно**. Дневной бюджет в валюте аккаунта.
- `maxPrice` — **необязательно**. Предельная ставка в валюте аккаунта.
- `price` — **необязательно**. Цена оптимизируемого события в валюте аккаунта.
- `dateStart` — **необязательно**. Дата начала, YYYY-MM-DD.
- `dateEnd` — **необязательно**. Дата окончания, YYYY-MM-DD.
- `targetings` — **необязательно**. Структура таргетинга, отправляется как есть.
- `extra` — **необязательно**. Дополнительные поля, подмешиваемые в тело запроса как есть.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в VK Рекламе

Инструмент изменяет реальные данные VK Рекламы так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Создать группу объявлений в VK Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Таргетинг задаётся в `targetings` (например, {"geo":{"regions":[188]},"age":{"age_list":[25,26]}}). Денежные поля — в валюте аккаунта. Остальные поля — через `extra`.

Доступ также зависит от прав токена, квот и ограничений исходного API.
