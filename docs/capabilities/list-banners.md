# VK Реклама: Список объявлений (banners) — MCP-инструмент (tool)

**MCP-инструмент (tool) для VK Рекламы:** Возвращает список banner (объект объявления/креатива в VK Рекламе) с необязательной фильтрацией по id, родительской группе объявлений и статусу.

Техническое имя: `list_banners`

## Какую задачу решает

> Я хочу посмотреть объявлений (banners).

Возвращает список banner (объект объявления/креатива в VK Рекламе) с необязательной фильтрацией по id, родительской группе объявлений и статусу.

## Когда использовать

Используйте эту возможность, когда нужен результат «Список объявлений (banners)» без ручной работы в интерфейсе VK Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `ids` — **необязательно**. Фильтр по id объявлений.
- `adGroupIds` — **необязательно**. Фильтр по id родительских групп объявлений.
- `statuses` — **необязательно**. Фильтр по статусу.
- `fields` — **необязательно**. Поля объявления в ответе.
- `limit` — **необязательно**. Сколько объектов на страницу (не больше 250).
- `offset` — **необязательно**. Смещение постраничной выдачи (сколько объектов пропустить).
- `autoPaginate` — **необязательно**. Забрать все страницы, идя по offset/count (limit при этом не ограничивает общее число объектов).

## Что вернёт

Возвращает список banner (объект объявления/креатива в VK Рекламе) с необязательной фильтрацией по id, родительской группе объявлений и статусу.

## Что изменится в VK Рекламе

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Посмотреть объявлений (banners) в VK Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

moderation_status (pending/allowed/banned) и delivery объясняют, почему объявление показывается или не показывается.

Доступ также зависит от прав токена, квот и ограничений исходного API.
