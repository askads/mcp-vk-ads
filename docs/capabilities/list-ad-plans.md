# VK Реклама: Список кампаний (ad_plans) — MCP-инструмент (tool)

**MCP-инструмент (tool) для VK Рекламы:** Возвращает список ad_plan (верхнеуровневый объект кампании в VK Рекламе) с необязательной фильтрацией по id и статусу.

Техническое имя: `list_ad_plans`

## Какую задачу решает

> Я хочу посмотреть кампаний (ad_plans).

Возвращает список ad_plan (верхнеуровневый объект кампании в VK Рекламе) с необязательной фильтрацией по id и статусу.

## Когда использовать

Используйте эту возможность, когда нужен результат «Список кампаний (ad_plans)» без ручной работы в интерфейсе VK Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `ids` — **необязательно**. Фильтр по id кампаний.
- `statuses` — **необязательно**. Фильтр по статусу.
- `fields` — **необязательно**. Поля кампании в ответе.
- `limit` — **необязательно**. Сколько объектов на страницу (не больше 250).
- `offset` — **необязательно**. Смещение постраничной выдачи (сколько объектов пропустить).
- `autoPaginate` — **необязательно**. Забрать все страницы, идя по offset/count (limit при этом не ограничивает общее число объектов).

## Что вернёт

Возвращает список ad_plan (верхнеуровневый объект кампании в VK Рекламе) с необязательной фильтрацией по id и статусу.

## Что изменится в VK Рекламе

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Посмотреть кампаний (ad_plans) в VK Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Денежные поля (budget_limit, budget_limit_day, max_price) — в валюте аккаунта.

Доступ также зависит от прав токена, квот и ограничений исходного API.
