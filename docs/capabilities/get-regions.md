# VK Реклама: Список регионов — MCP-инструмент (tool)

**MCP-инструмент (tool) для VK Рекламы:** Возвращает гео-регионы VK Рекламы (id, name, type), при необходимости отфильтрованные по подстроке названия.

Техническое имя: `get_regions`

## Какую задачу решает

> Я хочу найти регионы для таргетинга.

Возвращает гео-регионы VK Рекламы (id, name, type), при необходимости отфильтрованные по подстроке названия.

## Когда использовать

Используйте эту возможность, когда нужен результат «Список регионов» без ручной работы в интерфейсе VK Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `query` — **необязательно**. Подстрока для фильтра по названию региона, без учёта регистра (например, «Москва»).
- `limit` — **необязательно**. Сколько регионов вернуть после фильтрации. По умолчанию 50.

## Что вернёт

Возвращает гео-регионы VK Рекламы (id, name, type), при необходимости отфильтрованные по подстроке названия.

## Что изменится в VK Рекламе

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Найти регионы для таргетинга в VK Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Id регионов нужны для гео-таргетинга группы объявлений.

Доступ также зависит от прав токена, квот и ограничений исходного API.
