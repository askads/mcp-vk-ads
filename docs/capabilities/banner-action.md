# VK Реклама: Действие над объявлением — MCP-инструмент (tool)

**MCP-инструмент (tool) для VK Рекламы:** Меняет статус объявлений по id: activate (status=active), stop (status=blocked) или delete (status=deleted).

Техническое имя: `banner_action`

## Какую задачу решает

> Я хочу выполнить действие над объявлением.

Меняет статус объявлений по id: activate (status=active), stop (status=blocked) или delete (status=deleted).

## Когда использовать

Используйте эту возможность, когда нужен результат «Действие над объявлением» без ручной работы в интерфейсе VK Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `action` — **обязательно**. Действие из перечня, указанного в описании инструмента.
- `ids` — **обязательно**. Id объявлений, к которым применить действие.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в VK Рекламе

Исходный код помечает весь вызов «Действие над объявлением» как опасный. Конкретное воздействие зависит от переданного действия и описано ниже; перед вызовом проверьте параметры и обратимость результата.

## Пример запроса

> Выполнить действие над объявлением в VK Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их. Сначала покажи, какие данные изменятся, и дождись подтверждения.

## Возможные ошибки и ограничения

Проверьте обязательные параметры, права токена и актуальные ограничения исходного API.

Доступ также зависит от прав токена, квот и ограничений исходного API.
