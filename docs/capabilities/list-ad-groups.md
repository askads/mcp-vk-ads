# VK Реклама: Список групп объявлений — MCP-инструмент (tool)

**MCP-инструмент (tool) для VK Рекламы:** Возвращает список групп объявлений с необязательной фильтрацией по id, родительской кампании и статусу.

Техническое имя: `list_ad_groups`

## Какую задачу решает

> Я хочу посмотреть групп объявлений.

Возвращает список групп объявлений с необязательной фильтрацией по id, родительской кампании и статусу.

## Когда использовать

Используйте эту возможность, когда нужен результат «Список групп объявлений» без ручной работы в интерфейсе VK Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `ids` — **необязательно**. Фильтр по id групп объявлений.
- `adPlanIds` — **необязательно**. Фильтр по id родительских кампаний.
- `statuses` — **необязательно**. Фильтр по статусу.
- `fields` — **необязательно**. Поля группы объявлений в ответе (с «targetings» вернётся полный объект таргетинга).
- `limit` — **необязательно**. Сколько объектов на страницу (не больше 250).
- `offset` — **необязательно**. Смещение постраничной выдачи (сколько объектов пропустить).
- `autoPaginate` — **необязательно**. Забрать все страницы, идя по offset/count (limit при этом не ограничивает общее число объектов).

## Что вернёт

Возвращает список групп объявлений с необязательной фильтрацией по id, родительской кампании и статусу.

## Что изменится в VK Рекламе

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Посмотреть групп объявлений в VK Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Денежные поля — в валюте аккаунта; в `targetings` лежит структура таргетинга по гео, демографии и интересам.

Доступ также зависит от прав токена, квот и ограничений исходного API.
