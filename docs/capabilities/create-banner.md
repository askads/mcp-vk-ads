# VK Реклама: Создать объявление (banner) — MCP-инструмент (tool)

**MCP-инструмент (tool) для VK Рекламы:** Создаёт объявление внутри группы объявлений.

Техническое имя: `create_banner`

## Какую задачу решает

> Я хочу создать объявление (banner).

Создаёт объявление внутри группы объявлений.

## Когда использовать

Используйте эту возможность, когда нужен результат «Создать объявление (banner)» без ручной работы в интерфейсе VK Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `adGroupId` — **обязательно**. Id родительской группы объявлений.
- `name` — **необязательно**. Название объявления.
- `textblocks` — **необязательно**. Текстовые блоки, например {"title":{"text":"..."},"text":{"text":"..."}}.
- `urls` — **необязательно**. Объекты ссылок, например {"primary":{"url":"https://..."}}.
- `content` — **необязательно**. Ссылки на содержимое креатива (id загруженных медиа).
- `extra` — **необязательно**. Дополнительные поля объявления, подмешиваемые в тело запроса как есть.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в VK Рекламе

Инструмент изменяет реальные данные VK Рекламы так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Создать объявление (banner) в VK Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Креатив ссылается на загруженные медиа через `content`, тексты объявления — в `textblocks`, ссылки — в `urls`. Эти структуры отправляются как есть; точная форма для каждого формата объявления — в документации VK Рекламы.

Доступ также зависит от прав токена, квот и ограничений исходного API.
