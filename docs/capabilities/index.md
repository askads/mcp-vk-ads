# MCP-возможности VK Рекламы

Каталог содержит 18 публичных страниц — по одной для каждого зарегистрированного MCP-инструмента (tool) репозитория `mcp-vk-ads`. Страницы начинаются с задачи пользователя, объясняют результат и отдельно показывают, изменит ли вызов реальные данные.

Используйте этот каталог для выбора готовой возможности. Полные схемы параметров и ответы API остаются в [техническом справочнике](../TOOLS.md).

## Группы объявлений

- [Действие над группой объявлений](./ad-group-action.md) — Меняет статус групп объявлений по id: activate (status=active), stop (status=blocked) или delete (status=deleted). **Воздействие:** опасная операция.
- [Создать группу объявлений](./create-ad-group.md) — Создаёт группу объявлений внутри кампании. **Воздействие:** изменяет данные.
- [Список групп объявлений](./list-ad-groups.md) — Возвращает список групп объявлений с необязательной фильтрацией по id, родительской кампании и статусу. **Воздействие:** только чтение.
- [Изменить группу объявлений](./update-ad-group.md) — Меняет у группы объявлений название, бюджеты, предельную ставку, даты или таргетинг. **Воздействие:** изменяет данные.

## Кампании

- [Действие над кампанией](./ad-plan-action.md) — Меняет статус кампаний по id: activate (status=active), stop (status=blocked) или delete (status=deleted). **Воздействие:** опасная операция.
- [Создать кампанию (ad_plan)](./create-ad-plan.md) — Создаёт кампанию (ad_plan). **Воздействие:** изменяет данные.
- [Список кампаний (ad_plans)](./list-ad-plans.md) — Возвращает список ad_plan (верхнеуровневый объект кампании в VK Рекламе) с необязательной фильтрацией по id и статусу. **Воздействие:** только чтение.
- [Изменить кампанию (ad_plan)](./update-ad-plan.md) — Меняет у кампании название, бюджеты, предельную ставку или даты. **Воздействие:** изменяет данные.

## Объявления

- [Действие над объявлением](./banner-action.md) — Меняет статус объявлений по id: activate (status=active), stop (status=blocked) или delete (status=deleted). **Воздействие:** опасная операция.
- [Создать объявление (banner)](./create-banner.md) — Создаёт объявление внутри группы объявлений. **Воздействие:** изменяет данные.
- [Список объявлений (banners)](./list-banners.md) — Возвращает список banner (объект объявления/креатива в VK Рекламе) с необязательной фильтрацией по id, родительской группе объявлений и статусу. **Воздействие:** только чтение.
- [Изменить объявление (banner)](./update-banner.md) — Меняет у объявления название, текстовые блоки или ссылки. **Воздействие:** изменяет данные.

## Аккаунт

- [Баланс аккаунта](./get-balance.md) — Возвращает текущий баланс аккаунта VK Рекламы: доступные средства и валюту. **Воздействие:** только чтение.
- [Список регионов](./get-regions.md) — Возвращает гео-регионы VK Рекламы (id, name, type), при необходимости отфильтрованные по подстроке названия. **Воздействие:** только чтение.
- [Лимиты запросов к API](./get-throttling.md) — Возвращает текущие лимиты запросов VK Рекламы и их остаток (throttling.json) — чтобы не упереться в лимит. **Воздействие:** только чтение.
- [Информация об аккаунте](./get-user-info.md) — Возвращает информацию о текущем аккаунте VK Рекламы (user.json), включая additional_info.client_name. **Воздействие:** только чтение.

## Статистика

- [Статистика](./get-statistics.md) — Возвращает статистику по кампаниям (ad_plans), группам объявлений (ad_groups) или объявлениям (banners) из сервиса статистики VK Рекламы v3. **Воздействие:** только чтение.

## Дополнительные методы API

- [Произвольный запрос к API VK Рекламы](./raw-request.md) — Универсальный запрос напрямую к любому эндпоинту API VK Рекламы (например, path "v2/ad_plans.json", method GET). **Воздействие:** опасная операция.
