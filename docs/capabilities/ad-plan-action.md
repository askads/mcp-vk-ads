# VK Реклама: Действие над кампанией — MCP-инструмент (tool)

**MCP-инструмент (tool) для VK Рекламы:** Меняет статус кампаний по id: activate (status=active), stop (status=blocked) или delete (status=deleted).

Техническое имя: `ad_plan_action`

## Какую задачу решает

> Я хочу выполнить действие над кампанией.

Меняет статус кампаний по id: activate (status=active), stop (status=blocked) или delete (status=deleted).

## Когда использовать

Используйте эту возможность, когда нужен результат «Действие над кампанией» без ручной работы в интерфейсе VK Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `action` — **обязательно**. Действие из перечня, указанного в описании инструмента.
- `ids` — **обязательно**. Id кампаний, к которым применить действие.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в VK Рекламе

Исходный код помечает весь вызов «Действие над кампанией» как опасный. Конкретное воздействие зависит от переданного действия и описано ниже; перед вызовом проверьте параметры и обратимость результата.

## Пример запроса

> Выполнить действие над кампанией в VK Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их. Сначала покажи, какие данные изменятся, и дождись подтверждения.

## Возможные ошибки и ограничения

Проверьте обязательные параметры, права токена и актуальные ограничения исходного API.

Доступ также зависит от прав токена, квот и ограничений исходного API.
