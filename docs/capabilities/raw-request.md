# VK Реклама: Произвольный запрос к API VK Рекламы — MCP-инструмент (tool)

**MCP-инструмент (tool) для VK Рекламы:** Универсальный запрос напрямую к любому эндпоинту API VK Рекламы (например, path "v2/ad_plans.json", method GET).

Техническое имя: `raw_request`

## Какую задачу решает

> Я хочу выполнить дополнительный запрос к API.

Универсальный запрос напрямую к любому эндпоинту API VK Рекламы (например, path "v2/ad_plans.json", method GET).

## Когда использовать

Используйте эту возможность, когда нужен результат «Произвольный запрос к API VK Рекламы» без ручной работы в интерфейсе VK Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `path` — **обязательно**. Путь эндпоинта с версией, например "v2/ad_plans.json", "v3/statistics/banners/day.json".
- `method` — **необязательно**. HTTP-метод. По умолчанию GET.
- `query` — **необязательно**. Параметры строки запроса (фильтры, поля, постраничная выдача).
- `body` — **необязательно**. JSON-тело для POST-запросов.
- `confirmWrite` — **необязательно**. Должен быть true для записи (POST или DELETE).

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в VK Рекламе

Исходный код помечает весь вызов «Произвольный запрос к API VK Рекламы» как опасный. Конкретное воздействие зависит от переданного действия и описано ниже; перед вызовом проверьте параметры и обратимость результата.

## Пример запроса

> Выполнить дополнительный запрос к API в VK Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их. Сначала покажи, какие данные изменятся, и дождись подтверждения.

## Возможные ошибки и ограничения

Нужен для эндпоинтов, у которых нет отдельного инструмента. `query` уходит в строку запроса, `body` отправляется как JSON для POST. GET выполняется свободно; POST и DELETE — запись, для них нужен confirmWrite=true.

Доступ также зависит от прав токена, квот и ограничений исходного API.

## Связанные MCP-инструменты

Связанных специализированных инструментов в этой группе нет.
