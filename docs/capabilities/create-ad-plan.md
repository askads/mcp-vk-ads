# VK Реклама: Создать кампанию (ad_plan) — MCP-инструмент (tool)

**MCP-инструмент (tool) для VK Рекламы:** Создаёт кампанию (ad_plan).

Техническое имя: `create_ad_plan`

## Какую задачу решает

> Я хочу создать кампанию (ad_plan).

Создаёт кампанию (ad_plan).

## Когда использовать

Используйте эту возможность, когда нужен результат «Создать кампанию (ad_plan)» без ручной работы в интерфейсе VK Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `name` — **обязательно**. Название кампании.
- `objective` — **необязательно**. Цель кампании, например site_conversions, leadads, traffic.
- `autobiddingMode` — **необязательно**. Стратегия аукциона, например max_goals, fixed, second_price_mean.
- `budgetLimit` — **необязательно**. Общий бюджет в валюте аккаунта.
- `budgetLimitDay` — **необязательно**. Дневной бюджет в валюте аккаунта.
- `maxPrice` — **необязательно**. Предельная ставка в валюте аккаунта.
- `dateStart` — **необязательно**. Дата начала, YYYY-MM-DD.
- `dateEnd` — **необязательно**. Дата окончания, YYYY-MM-DD.
- `extra` — **необязательно**. Дополнительные поля кампании, подмешиваемые в тело запроса (например, priced_goal, pricelist_id).

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в VK Рекламе

Инструмент изменяет реальные данные VK Рекламы так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Создать кампанию (ad_plan) в VK Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Денежные поля — в валюте аккаунта. Сложные и редкие поля передаются через `extra` (подмешиваются в тело запроса как есть).

Доступ также зависит от прав токена, квот и ограничений исходного API.
