# VK Реклама: Информация об аккаунте — MCP-инструмент (tool)

**MCP-инструмент (tool) для VK Рекламы:** Возвращает информацию о текущем аккаунте VK Рекламы (user.json), включая additional_info.client_name.

Техническое имя: `get_user_info`

## Какую задачу решает

> Я хочу получить информацию об аккаунте.

Возвращает информацию о текущем аккаунте VK Рекламы (user.json), включая additional_info.client_name.

## Когда использовать

Используйте эту возможность, когда нужен результат «Информация об аккаунте» без ручной работы в интерфейсе VK Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `fields` — **необязательно**. Поля пользователя в ответе. По умолчанию — базовый набор.

## Что вернёт

Возвращает информацию о текущем аккаунте VK Рекламы (user.json), включая additional_info.client_name.

## Что изменится в VK Рекламе

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Получить информацию об аккаунте в VK Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Позволяет убедиться, на какой аккаунт рекламодателя указывает токен.

Доступ также зависит от прав токена, квот и ограничений исходного API.
