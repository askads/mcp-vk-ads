# VK Реклама: Изменить объявление (banner) — MCP-инструмент (tool)

**MCP-инструмент (tool) для VK Рекламы:** Меняет у объявления название, текстовые блоки или ссылки.

Техническое имя: `update_banner`

## Какую задачу решает

> Я хочу изменить объявление (banner).

Меняет у объявления название, текстовые блоки или ссылки.

## Когда использовать

Используйте эту возможность, когда нужен результат «Изменить объявление (banner)» без ручной работы в интерфейсе VK Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `id` — **обязательно**. Id изменяемого объявления.
- `name` — **необязательно**. Новое название.
- `textblocks` — **необязательно**. Новые текстовые блоки взамен прежних, отправляются как есть.
- `urls` — **необязательно**. Новые объекты ссылок взамен прежних, отправляются как есть.
- `extra` — **необязательно**. Дополнительные поля, подмешиваемые в тело запроса как есть.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в VK Рекламе

Инструмент изменяет реальные данные VK Рекламы так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Изменить объявление (banner) в VK Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Для смены статуса — banner_action. Структуры отправляются как есть.

Доступ также зависит от прав токена, квот и ограничений исходного API.
